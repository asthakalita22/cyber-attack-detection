# cyber-attack-detection
Cyber Attack Detection System is a web-based security application that detects and classifies cyber attacks using Machine Learning and rule-based analysis. The system analyzes network-related input data and identifies threats such as DoS attacks, brute force attacks, port scans, and privilege escalation attempts. It provides real-time detection results along with severity levels (LOW, MEDIUM, HIGH, CRITICAL) through an interactive web interface. Built using Python, Flask, Scikit-learn, Pandas, and basic web technologies, the project also includes preset attack simulations for testing and demonstration purposes.
